# Chrome Bookmarks Manager v1.0.0

First stable personal-use release of Chrome Bookmarks Manager for Windows 10 / Windows 11 x64.

## Included

- Chrome native Bookmarks loading and large-library browsing
- Name / URL / domain-text search
- Add, rename, URL edit, move, reorder, and Drag & Drop
- Single and batch delete / move
- Undo / Redo
- Explicit Safe Save with source-baseline conflict detection
- Verified application-owned backup before atomic replacement
- Chrome-running Save protection
- Chromium-compatible checksum regeneration and post-write validation
- Self-contained single-file Windows EXE

## Safe use

Chrome should be fully closed before Save. The application blocks direct Save when Chrome is detected running and blocks overwrite when the loaded source has changed externally.

## Integrity

Verify `ChromeBookmarksManager.exe` against the attached `ChromeBookmarksManager.exe.sha256` file before use when you want an independent download-integrity check.
