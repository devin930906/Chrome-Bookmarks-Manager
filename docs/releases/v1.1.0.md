# Chrome Bookmarks Manager v1.1.0

V1.1.0 adds a complete Simplified Chinese / English interface and a branded Windows application icon while preserving the V1.0 Safe Save and large-library behavior.

## Highlights

- Simplified Chinese is the default language on first launch
- Instant in-app switching between Simplified Chinese and English
- The selected language is remembered for future launches
- Localized menus, toolbar controls, search scopes, dialogs, status text, history descriptions, and typed error messages
- New branded multi-size Windows application icon for the EXE, main window, taskbar, and Alt+Tab
- Application version updated to 1.1.0
- Existing Chrome bookmark data format and explicit Safe Save semantics remain unchanged

## Safety

Language preferences are stored separately from Chrome bookmark data. Switching languages does not modify the loaded Chrome `Bookmarks` file.

Saving remains explicit and guarded: Chrome must be fully closed, the source baseline must still match, an application-owned backup is verified before atomic replacement, and the written result is reopened and validated.

## Compatibility

- Windows 10 / Windows 11 x64
- Self-contained single-file EXE
- No .NET runtime installation required for normal use

## Integrity

The release contains:

- `ChromeBookmarksManager.exe`
- `ChromeBookmarksManager.exe.sha256`

Verify the EXE against the attached SHA-256 file when you want an independent download-integrity check.
