# Chrome Bookmarks Manager v1.1.1

V1.1.1 is a visual maintenance release that refreshes the Windows application icon while preserving the complete V1.1 bilingual interface and all existing bookmark-management and Safe Save behavior.

## Highlights

- Refreshed branded Windows application icon
- New icon is used by the EXE, main window, taskbar, and Alt+Tab
- Application version updated to 1.1.1
- Simplified Chinese remains the default language on first launch
- Instant Simplified Chinese / English switching and remembered language preference remain unchanged
- Bookmark reading, editing, search, Undo/Redo, import/export, and explicit Safe Save behavior remain unchanged

## Verification

- Full xUnit suite: 425 / 425 passed
- Windows Release build passed
- Self-contained single-file publish passed
- Windows startup smoke test passed
- V1.1.1 icon contract passed
- EXE version 1.1.1 verification passed
- Windows owner visual acceptance of the refreshed icon completed

## Safety

This release does not change the Chrome bookmark data model or persistence rules.

Saving remains explicit and guarded: Chrome must be fully closed, the accepted source baseline must still match, an application-owned backup is verified before atomic replacement, and the written result is reopened and validated.

## Compatibility

- Windows 10 / Windows 11 x64
- Self-contained single-file EXE
- No separate .NET runtime installation required for normal use
