# Chrome Bookmarks Manager v1.2.1

V1.2.1 is a focused folder-creation parity and usability release. It keeps the complete V1.2.0 feature set and existing Safe Save protections while making new-folder creation behave more like Chrome.

## Highlights

- Add Folder is now available from the right contents-pane context menu.
- The Edit menu, left folder tree, and right contents pane all reuse the same folder-creation path.
- New-folder dialogs start with a localized default name:
  - Simplified Chinese: `新建文件夹`
  - English: `New folder`
- The default name is automatically selected when the dialog opens, so typing immediately replaces it.
- Confirming without changing the text creates the folder with the displayed default name.

## Behavior and safety

This release does not change the Chrome bookmark file format or weaken the existing persistence boundary.

- Folder creation remains an in-memory edit until the user explicitly saves.
- Existing Dirty-state tracking remains active.
- Existing Undo / Redo history for folder creation remains active.
- Chrome-running Save protection, source-baseline conflict detection, verified backup creation, atomic replacement, and post-write validation remain unchanged.
- The right-pane entry point creates the folder in the currently selected/open folder, matching the existing application model.
