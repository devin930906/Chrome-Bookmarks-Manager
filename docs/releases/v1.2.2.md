# Chrome Bookmarks Manager v1.2.2

V1.2.2 is a focused folder-navigation behavior fix.

## What changed

When a new child folder is created inside the currently open folder, the application now stays in that current parent folder instead of automatically navigating into the newly created folder.

The new folder is immediately visible in the current contents list, so repeated folder creation or other work can continue without having to navigate back after every new folder.

## Preserved behavior

This release keeps the V1.2.1 folder-creation experience:

- Add Folder remains available from the Edit menu, left folder tree, and right contents pane.
- The default folder name remains localized:
  - Simplified Chinese: `新建文件夹`
  - English: `New folder`
- The default name remains selected for immediate overwrite.
- Folder creation remains undoable and redoable.
- Dirty-state tracking remains unchanged.
- Safe Save protections remain unchanged.

## Regression coverage

Automated tests now verify that after `AddFolderAsync` succeeds:

- the created folder belongs to the current parent
- the current parent remains the selected navigation folder
- the new folder appears in the current contents projection
- document and selection summaries are refreshed correctly

## Compatibility

- Windows 10 / Windows 11 x64
- Self-contained single-file EXE
- No separate .NET runtime installation required for normal use

## Integrity

The formal release contains exactly:

- `ChromeBookmarksManager.exe`
