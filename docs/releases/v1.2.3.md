# Chrome Bookmarks Manager v1.2.3

## Changes

- Added **Add Bookmark...** to the right contents-pane context menu, alongside bulk add and folder creation.
- Fixed Safe Save for detached Chrome `Bookmarks` copies. A separately copied backup / working file can now be saved even when Chrome is running.
- Retained the Chrome-running safety block for standard live Chrome profile `Bookmarks` files under the normal Windows Chrome profile locations.
- Retained source-baseline conflict detection, verified pre-replace backups, validated temporary output, atomic replacement, and post-write validation.
- Updated bilingual Save tooltips and error text so the live-profile restriction is explicit instead of implying that every `Bookmarks` file requires Chrome to be closed.
- Added regression coverage for detached-copy saving, live-profile blocking, source-path classification, and the right-pane single-bookmark command.

## Safety boundary

V1.2.3 does **not** disable the Chrome-running protection globally. It narrows that protection to standard live Chrome profile `Bookmarks` files. Detached copies outside those live profile locations do not belong to the running Chrome process and therefore no longer fail Save merely because Chrome is open.

The existing verified-backup and atomic-replacement transaction remains unchanged.

## Release assets

The formal release contains only:

- `ChromeBookmarksManager.exe`
- `ChromeBookmarksManager.exe.sha256`
