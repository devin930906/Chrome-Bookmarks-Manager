# Chrome Bookmarks Manager v1.2.5

## Windows taskbar icon display fix

V1.2.5 fixes the branded blue bookmark icon appearing clipped or incomplete in the Windows taskbar. The original ICO file contained incorrect internal directory offsets and lengths for high-resolution frames.

### Changes

- Rebuilt the Windows application icon with valid 16×16, 24×24, 32×32, 48×48, 64×64 and 128×128 RGBA PNG frames.
- Preserved the established blue bookmark icon design across supported sizes.
- Strengthened the icon verification gate: frame offsets and lengths, PNG signatures and dimensions, PNG CRC values, lossless decompression, alpha visibility and file boundaries are now checked in CI.
- Kept the EXE and WPF main window icon references consistent.
- No changes to bookmark loading, editing, searching, saving, or other application behavior.

### Validation

- The fix passed the Windows automated build and tests.
- The project owner confirmed the repaired icon displays completely in the Windows taskbar on 19 October 2026.
- The official v1.2.5 release workflow separately runs release readiness, Windows x64 publish, EXE smoke test, version verification and SHA256 integrity checks.

### Compatibility and update notes

- Target: Windows x64, self-contained single-file .NET 10 WPF application.
- This update replaces the application executable; bookmark files and saved preferences do not need migration.
- If Windows continues showing the old cached taskbar graphic, close the app, unpin the previous shortcut, launch the new EXE and pin it again.

### Previous fixes retained

- v1.2.4 Chromium-native JSON text serialization and Unicode handling.
- v1.2.3 right-pane Add Bookmark command and safe detached-file saves.
- Verified Safe Save, backup, source-conflict detection, atomic replacement, undo/redo, multilingual interface and large-library support.
