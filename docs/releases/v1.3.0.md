# Chrome Bookmarks Manager v1.3.0

## 全新工作台 UI · 浅色 / 暗黑模式

- 按「夜航工作台」方向重新设计主界面，采用左侧文件夹、中间书签列表、右侧项目详情的三栏布局。
- 详情栏支持收起及重新打开，窄窗口自动收起，保留搜索与常用操作空间。
- 新增 **浅色模式（Light Mode）** 和 **暗黑模式（Dark Mode）**。通过顶部「切换模式」按钮，或「视图 → 浅色模式 / 暗黑模式 / 外观」即时切换，无需重启。
- 分别记住主题与语言选择，下一次启动继续使用上次设置。
- 切换主题保留当前文档、搜索结果、选中项、目录展开、未保存修改和撤销 / 重做历史。
- 统一菜单、按钮、输入控件、书签编辑、批量添加、移动和确认对话框的外观与焦点状态。
- 保留原有搜索、编辑、拖放、批量操作、剪贴板、HTML 导入 / 导出及 Safe Save 安全保存功能。
- 修正当前主题菜单重复点击后的勾选状态，以及长列表滚动条尺寸。

## 下载与升级

正式下载文件为下方 Assets 中的：

- **ChromeBookmarksManager.exe** — Windows x64 自包含单文件程序，无需单独安装 .NET。
- **ChromeBookmarksManager.exe.sha256** — 对应 EXE 的 SHA256 校验文件。

这些是正式 Release 附件，不使用一天有效的 Actions 临时构建。关闭旧程序后，将新版 EXE 放在你希望使用的位置运行。现有书签文件和语言配置无需迁移；旧配置缺少主题设置时默认使用暗黑模式。程序仍采用显式保存，修改不会因为切换主题而自动写入书签文件。

Windows 原生文件选择窗口遵循系统外观。本版本的自动验证使用合成书签数据；不代表已经完成用户真实书签上的人工验收。

## 验证

正式发布流程执行完整测试、原有界面与保存安全契约、规模与性能测量、Windows x64 打包、EXE 启动检查、版本一致性及 SHA256 完整性检查。发布标签、项目版本、EXE ProductVersion 均为 **1.3.0**，FileVersion 为 **1.3.0.0**。

## English

V1.3.0 introduces the redesigned three-column Night Workspace UI and persistent Light / Dark modes. Switch immediately using the toolbar or View → Appearance, without losing the current document, search, selection, unsaved edits or undo/redo history. Menus, controls and application dialogs follow the active theme; native file pickers follow Windows.

Existing bookmark editing, search, drag and drop, bulk operations, clipboard, HTML import/export and Safe Save protections are retained. Close the previous application and run the new self-contained Windows x64 EXE. Bookmark files and saved language preferences need no migration. Official assets are the EXE and its SHA256 checksum; these Release downloads do not expire after one day.
