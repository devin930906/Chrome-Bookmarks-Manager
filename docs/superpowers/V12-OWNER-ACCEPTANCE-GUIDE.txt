PURPOSE
This guide validates the V1.2 external Bookmarks drag-and-drop and bulk URL/TXT import features before merge. It intentionally uses a disposable copy first so the production Chrome Bookmarks file is not modified during feature acceptance.

HARD SAFETY RULES
1. Do not replace the installed/stable V1.1.1 executable yet.
2. Do not merge PR #18 until every required V1.2 owner-acceptance item passes.
3. First test against a disposable COPY of the Chrome Bookmarks file, not the production source.
4. Keep an independent backup of the production Bookmarks file outside the Chrome profile before any real Save.
5. Do not upload, commit, paste, or screenshot private bookmark titles, URLs, raw Bookmarks JSON, profile paths, or backup contents.
6. V1.2 external file drop accepts only a file whose file name is exactly Bookmarks (case-insensitive). Chrome's Bookmarks.bak and unrelated HTML/TXT/JSON files must not be treated as the native Bookmarks file.
7. TXT import is for the bulk-add dialog. TXT files must not be treated as native Bookmarks files when dragged onto the main window.

STEP 1 — DOWNLOAD THE REVIEWED CI ARTIFACT
Open GitHub Actions run #570 for PR #18.

Download:
ChromeBookmarksManager-win-x64

Required:
- ChromeBookmarksManager.exe exists.
- Do not overwrite the current stable V1.1.1 EXE yet.

STEP 2 — CREATE A DISPOSABLE BOOKMARKS COPY
Close Chrome before making the copy so the source is stable.

Find the active Chrome profile locally using:
chrome://version

The active native file is:
<Profile Path>\Bookmarks

Copy it to a temporary test folder and KEEP THE FILE NAME:
Bookmarks

Example concept only:
D:\CBM-V12-Test\Bookmarks

Do not rename the disposable test file to Bookmarks.txt or Bookmarks.json.

Re-open Chrome only after the copy has been made if desired. Note that Safe Save intentionally requires Chrome to be fully closed.

STEP 3 — EXTERNAL BOOKMARKS DRAG-AND-DROP
Start the reviewed V1.2 ChromeBookmarksManager.exe.

Without using File -> Open:
- drag the disposable file named Bookmarks from Windows File Explorer onto the main application window.

Required:
- the mouse indicates an accepted file drop;
- the Bookmarks document loads;
- URL/folder counts are plausible;
- the three permanent Chrome roots appear;
- normal folder browsing still works;
- internal bookmark/folder drag-and-drop still works after loading;
- there is no corruption/recovery warning.

PASS statement:

STEP 6 — MANUAL MULTILINE URL ENTRY
Paste only synthetic/non-private test URLs such as:

https://example.com/one
example.org/two
www.example.net/three
localhost:3000/test

Leave at least one blank line between entries.

Add the bookmarks.

Required:
- blank lines are ignored;
- four bookmarks are created;
- bare example.org/two becomes https://example.org/two;
- www.example.net/three becomes https://www.example.net/three;
- localhost:3000/test becomes https://localhost:3000/test;
- explicit https://example.com/one stays unchanged;
- generated names are usable host-based names rather than empty titles;
- the document becomes Dirty;
- the new bookmarks appear in the selected folder.

PASS statement:
V1.2 Manual Bulk URLs = PASS

Required:
