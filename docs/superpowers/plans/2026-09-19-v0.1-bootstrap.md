# V0.1 Bootstrap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Turn the documentation-only repository into a reproducible .NET 10 WPF baseline that builds, tests, publishes, smoke-tests, and produces a Windows x64 self-contained single-file EXE artifact in GitHub Actions without introducing Chrome bookmark write capability.

**Architecture:** V0.1 establishes only the application shell, project boundaries, test infrastructure, repository privacy guardrails, publish scripts, and CI. The executable contains a minimal WPF shell backed by a small testable ViewModel and explicit document state. Chrome bookmark parsing starts in V0.2.

**Tech Stack:** C# 14, .NET 10, WPF, XAML, xUnit, PowerShell, GitHub Actions.

**Spec:** docs/superpowers/specs/2026-09-19-chrome-bookmarks-manager-design.md

## Global Constraints

- Target Windows 10 / Windows 11 x64.
- Target framework is net10.0-windows.
- Distribution target is a self-contained single Windows EXE.
- Real private Chrome Bookmarks files must never enter GitHub or GitHub Actions.
- V0.1 contains no Chrome production write support.
- Prefer .NET BCL, WPF, and System.Text.Json; avoid convenience dependencies.
- main should remain buildable.
- Completion claims require build, test, publish, and runtime evidence.
- Current toolchain snapshot verified on 2026-09-19:
  - .NET SDK 10.0.401
  - actions/checkout@v7
  - actions/setup-dotnet@v6
  - actions/upload-artifact@v7
- Re-check those external tool versions before execution if implementation happens substantially later than 2026-09-19.

## Scope Boundary

This plan covers V0.1 only.

It intentionally does not implement Chrome Bookmarks parsing, search, editing, drag/drop, delete, undo/redo, checksum, backup, or Chrome write-back. Those capabilities receive milestone-specific plans after V0.1 is accepted.

## Review Focus

1. **Wrong SDK/toolchain selected** — pin .NET SDK 10.0.401 and have CI consume that pin.
2. **Private bookmark data accidentally tracked** — CI fails when production-style Bookmarks filenames or private-data paths are tracked.
3. **Publish output is not actually one EXE** — verification fails unless exactly one regular file exists and it is ChromeBookmarksManager.exe.
4. **WPF executable crashes immediately after launch** — smoke test launches the EXE, verifies it remains alive through startup, then terminates it.
5. **Synthetic fixture contains private/non-example URLs** — test rejects URL hosts outside reserved example domains.

~~~csharp
using System.Text.Json;

namespace ChromeBookmarksManager.Tests;

public sealed class SampleBookmarksFixtureTests
{
    private static string FixturePath =>
        Path.Combine(AppContext.BaseDirectory, "Fixtures", "Bookmarks.sample.json");

    [Fact]
    public void Fixture_IsValidJsonAndUsesVersionOne()
    {
        using var document = JsonDocument.Parse(File.ReadAllText(FixturePath));

        Assert.Equal(1, document.RootElement.GetProperty("version").GetInt32());
        Assert.True(document.RootElement.GetProperty("roots").TryGetProperty("bookmark_bar", out _));
        Assert.True(document.RootElement.GetProperty("roots").TryGetProperty("other", out _));
        Assert.True(document.RootElement.GetProperty("roots").TryGetProperty("synced", out _));
    }

    [Fact]
    public void Fixture_ContainsOnlyReservedExampleHosts()
    {
        using var document = JsonDocument.Parse(File.ReadAllText(FixturePath));
        var hosts = new List<string>();

        CollectHosts(document.RootElement, hosts);

        Assert.NotEmpty(hosts);
        Assert.All(hosts, host =>
            Assert.Contains(host, new[] { "example.com", "www.example.com", "example.net", "example.org" }));
    }

    private static void CollectHosts(JsonElement element, ICollection<string> hosts)
    {
        if (element.ValueKind == JsonValueKind.Object)
        {
            if (element.TryGetProperty("url", out var urlElement)
                && Uri.TryCreate(urlElement.GetString(), UriKind.Absolute, out var uri))
            {
                hosts.Add(uri.Host);
            }

            foreach (var property in element.EnumerateObject())
            {
                CollectHosts(property.Value, hosts);
            }

            return;
        }

        if (element.ValueKind == JsonValueKind.Array)
        {
            foreach (var child in element.EnumerateArray())
            {
                CollectHosts(child, hosts);
            }
        }
    }
}
~~~

- [ ] **Step 5: Add repository safety script**

Create scripts/Verify-RepositorySafety.ps1:

~~~powershell
$ErrorActionPreference = "Stop"

$trackedFiles = @(git ls-files)

if ($LASTEXITCODE -ne 0) {
    throw "git ls-files failed."
}

$forbidden = foreach ($path in $trackedFiles) {
    $normalized = $path -replace "\", "/"
    $leaf = [System.IO.Path]::GetFileName($normalized)
    $isApprovedFixture = $normalized -eq "samples/Bookmarks.sample.json"

    $looksLikeProductionBookmark =
        $leaf -eq "Bookmarks" -or
        $leaf -eq "Bookmarks.bak" -or
        $leaf -like "Bookmarks.backup-*" -or
        $leaf -eq "Bookmarks.tmp" -or
        ($leaf -like "Bookmarks.*" -and -not $isApprovedFixture)

    $isPrivatePath =
        $normalized -match '(^|/)(UserData|PrivateData)(/|$)' -or
        $normalized -match '(^|/)TestData/Private(/|$)'

    if ($looksLikeProductionBookmark -or $isPrivatePath) {
        $path
    }
}

if ($forbidden.Count -gt 0) {
    $separator = [Environment]::NewLine
    Write-Error ("Forbidden private bookmark paths are tracked:" + $separator + ($forbidden -join $separator))
    exit 1
}

Write-Host "Repository safety check passed."
~~~

## Task 6: Add a Windows runtime smoke test

**Files:**
- Create: scripts/SmokeTest-Windows.ps1

**Interfaces:**
- Consumes a published EXE path.
- Fails if the process terminates during startup observation.
- Terminates the process after a successful observation.

- [ ] **Step 1: Create the script**

~~~powershell
param(
    [Parameter(Mandatory = $true)]
    [string]$ExecutablePath,

    [int]$ObservationSeconds = 5
)

$ErrorActionPreference = "Stop"

if (-not (Test-Path $ExecutablePath -PathType Leaf)) {
    throw "Executable not found: $ExecutablePath"
}

$process = Start-Process -FilePath $ExecutablePath -PassThru

try {
    Start-Sleep -Seconds $ObservationSeconds
    $process.Refresh()

    if ($process.HasExited) {
        throw "Application exited during smoke-test startup. ExitCode=$($process.ExitCode)"
    }

    Write-Host "Smoke test passed. Process stayed alive for $ObservationSeconds seconds."
}
finally {
    if (-not $process.HasExited) {
        Stop-Process -Id $process.Id -Force
        $process.WaitForExit()
    }
}
~~~
