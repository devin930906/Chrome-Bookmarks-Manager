# V0.7 Delete / Batch Implementation Plan

> **Execution model:** Superpowers task-by-task development with RED -> GREEN evidence, focused commits, full Windows CI, final review, Windows 10 owner acceptance, merge, and post-merge verification.

**Goal:** Add safe in-memory single deletion, bookmark multi-selection, batch delete, and batch Move to... without introducing any Chrome source-file write path.

**Baseline:** V0.6 completed on `main` at `caddccc40228a40680a310e4871d80298459ac48`.

**Spec:** `docs/superpowers/specs/2026-09-20-v0.7-delete-batch-design.md`.

## Global constraints

- Windows 10 / Windows 11 x64.
- Preserve left folder tree + right bookmark list.
- Folder tree remains single-select.
- Bookmark list uses Extended multi-selection.
- Single bookmark delete, single folder subtree delete, batch bookmark delete, and batch bookmark Move to... are in scope.
- Search-result batch delete/move is allowed using underlying bookmark references.
- Rename/edit URL remain single-primary-bookmark operations.
- Permanent Chrome roots cannot be deleted.
- V0.7 remains in-memory only.
- No Save, writer, source overwrite, backup, replace, checksum regeneration, or Chrome process handling.
- Real private bookmark data never enters Git or CI.
- Behavior changes use RED -> GREEN tests.
