# Chrome 书签管理器：夜航工作台 UI 与双主题设计

日期：2026-10-23（Asia/Kuala_Lumpur）  
状态：用户已于 2026-10-23 确认，进入实施

## 1. 用户决定与目标

用户已从五套概念稿中选择第 2 套「夜航专业版」，要求沿此方向完善整个 UI、布局，保留现有全部功能，并新增浅色模式（Light Mode）与暗黑模式（Dark Mode）的切换。

目标：把当前 WPF 桌面程序改造成视觉统一的三栏书签工作台，同时维持大型书签库的可浏览性、键盘操作与原有安全保存边界。主窗口、菜单、右键菜单、应用内弹窗、错误和空状态都覆盖两种主题。

本设计没有授权发布 Release、覆盖用户正在使用的 EXE、修改真实书签、修改 Windows 全局外观，或改变 Chrome 配置。

## 2. 已比较的方向

前一轮展示了五个可操作概念：清透工作台、夜航专业版、暖白资料库、分栏探索者、专注搜索台。

| 可行路径 | 收益 | 代价 | 决定 |
|---|---|---|---|
| 明亮双栏工作台 | 熟悉、列表空间充足、迁移成本较低 | 所选项目的详情需要额外展开 | 未选为主方向 |
| 夜航三栏工作台 | 目录、列表、所选项目同时可见，适合整理 | 右侧详情会占用列表宽度 | 用户已选择；本设计采用 |
| 搜索优先界面 | 查找路径短，画面简洁 | 层级浏览与持续整理需要更多切换 | 未选为主方向 |

暖白资料库与分栏探索者也已展示；前者行高大、同屏项目少，后者横向占用大。保留夜航方向的布局，浅色模式沿用该布局，不切回另一套概念稿。

## 3. 本设计作出的默认选择

以下由设计者提出，用户可在本次设计确认时调整：

- 第一次使用、没有主题配置、配置缺失或非法时，默认暗黑模式，与用户已选择的视觉方向一致。
- 提供恰好两种模式：Light 与 Dark；本轮不增加跟随系统或定时切换。
- 主窗口右上常驻「切换模式」，显示日/月符号，提示当前主题和切换目标；辅助入口为「视图 → 浅色模式 / 暗黑模式」。
- 外观设置中的两个选项采用单选状态，展示中英文名称；点击即时生效并保存偏好。
- 保留 WPF 与当前 .NET 工程结构，不迁移到 WebView、Electron 或其他 UI 框架。
- 保留标准 Windows 窗口行为；不为视觉效果重做拖动、最大化、Alt+Tab 与窗口关闭机制。

## 4. 主窗口布局

默认窗口大小继续使用 1180 × 760（WPF DIP），最小 900 × 560。可根据最终 WPF 实机测量微调控件间距，不擅自提升最低屏幕要求。

### 4.1 顶部窗口与菜单

保留现有应用 Icon、标题、版本与未保存标记。菜单为「文件」「编辑」「视图」「语言」。新增「视图」承载主题与详情栏显隐，现有文件和编辑命令不删除。

常用按钮不全部堆到同一横排。搜索和保存属于文档级工具栏；新增、排序、撤销/重做靠近列表。

### 4.2 左侧文件夹栏

初始宽度约 190–220 DIP，保留可拖动分隔条。三个 Chrome 根目录保持真实顺序与原始名称。嵌套缩进、展开箭头、选中背景清楚；长名称省略并提供完整提示。文件夹树保留虚拟化和回收，不因样式套用而失效。

上方保留「打开书签文件」。下方显示当前源文件名/路径（可省略，但悬停可查完整路径）和文件状态。数量直接复用现有统计；不为装饰额外递归统计所有节点。

### 4.3 中间内容区

工具栏：搜索框、全部书签/当前文件夹范围选择、切换模式、明确的保存按钮。打开文件/加载取消继续可达，加载期间显示「取消加载」。

内容标题：当前位置、文件夹名称、当前显示数量、未保存标记。右侧提供撤销、重做、「＋ 添加」菜单；添加菜单同时包含单个书签、批量书签、文件夹。添加成功仍停留当前父文件夹。

列表：名称与网址两列，文件夹/书签有可辨识图形。默认紧凑行高约 38–44 DIP。使用轻分隔线与清楚的 hover、焦点、选中、多选和拖放目标状态。长标题和长 URL 省略，提示显示全文。使用本地矢量或现有资源，不为书签 favicon 发网络请求。

不改变原始混合子节点顺序。只有用户显式触发「按名称排序」才调用现有排序逻辑；浏览或主题切换不会自动排序。

多选后在列表上方显示批量操作栏：已选数量、剪切、复制、移动、删除、清除选择。Ctrl/Shift、Ctrl+A 与现有 SelectionMode=Extended 语义继续保留；复选框是辅助入口，不替换原有鼠标多选。

### 4.4 右侧详情栏

初始约 210–240 DIP。显示当前所选项目名称、网址（书签）、所在位置与类型，复用现有投影/节点数据。提供打开、重命名、编辑 URL、移动、删除等适用于该类型且可执行的入口。

可关闭并通过「详情」或「视图 → 详情栏」重新打开。窄窗口、125%/150% 缩放或长英文导致空间不足时允许自动收起，必须保留重新打开入口；中间列表应获得优先宽度。多选时显示选择数量和适用的批量操作，不能伪装成单个项目。

详情栏不遍历大型子树、不发请求、不提供不存在的网站预览/标签/同步/收藏功能。

### 4.5 底部状态

保留加载/错误/保存状态、搜索摘要、整份文档网址与文件夹计数、当前选择摘要、源文件路径。空间不足时对路径截断并提供完整提示，不永久隐藏状态字段。Dirty 状态使用文字和色彩同时提示。

## 5. 双主题视觉规则

| 语义 | 暗黑模式 | 浅色模式 |
|---|---|---|
| 内容底色 | 深灰 `#191C23` | 白 `#FFFFFF` |
| 侧栏/窗口底色 | 更深灰 `#13161C` | 冷浅灰 `#F5F6FA` |
| 次级表面 | `#20242D` | `#F0F2F7` |
| 主文字 | `#E4E8F0` | `#252D42` |
| 次级文字 | `#9BA5B6` | `#626F84` |
| 分隔线 | `#303641` | `#E0E4ED` |
| 强调色 | 淡紫 `#ABB6FF` | 靛蓝 `#5364D7` |
| 选中背景 | `#2D344F` | `#E9EDFF` |

颜色为首版 token，由最终对比度检查修正；不把大量颜色硬编码散落在控件里。常用文字约 12–14 DIP，标题约 20–24 DIP，正文必须能在 Windows 实际缩放下读取；状态文字不承担唯一操作说明。圆角约 4–8 DIP，弹窗约 10 DIP；不使用大范围毛玻璃、动画或逐行阴影。

覆盖菜单、子菜单、右键菜单、按钮、文本框、ComboBox、TreeView、ListView/GridView 表头、滚动条、分隔条、Tooltip、禁用/验证/拖放/焦点状态。错误、警告、成功保持可读，不能只依赖颜色。

应用自己的 WPF 对话框统一主题。原生打开/保存文件选择器继续使用 Windows 原生窗口，其外观由系统决定；不为应用主题修改系统全局设置。原生标题栏优先保持系统行为，支持的系统上可设置窗口级主题提示，失败时正常回退。

## 6. 主题切换行为与保存

主题切换即时应用到已打开的应用窗口和弹窗，不重启、不重新解析文档、不重建整个 ViewModel、不重建搜索索引。保持当前文件、目录展开、导航位置、滚动、搜索词/范围、所选项目、剪贴板语义、Dirty 状态与 Undo/Redo 栈。

读取 `UserSettingsStore` 的现有配置：`%LocalAppData%/ChromeBookmarksManager/settings.json`。新增规范化的 `theme` 字段（`light` / `dark`），与已有 `language` 共存。

必须修复设置写入的互相覆盖风险：当前 `SaveLanguage()` 序列化的是只含 Language 的 record，不能仅新加一个独立 SaveTheme() 然后继续全覆盖文件。两个设置入口必须读取/保留另一项或通过同一个完整设置模型写回；本轮不扩展到多进程设置同步。

配置缺失、旧版只有 language、字段非法、JSON 损坏、文件读权限不足时有明确默认值。保存配置失败时主题仍应用到当前会话，显示「本次已切换，但无法记住设置」之类非破坏提示；不假装下次会保存成功。保存语言也不能重置主题，保存主题不能重置语言。

应用级主题 ResourceDictionary 与本地化字符串字典分开管理。`LocalizationService` 切换语言时只替换本地化字典，不能清空主题词典；反向同理。启动时在窗口显示前加载主题，减少白色闪屏。

## 8. 弹窗与状态

- 添加/重命名/编辑 URL：明确标题、目标文件夹、输入标签、行内验证、确定/取消。名称全选规则沿用已有实现。
- 批量添加：多行框、TXT 导入、无效行编号、整批原子行为、一次撤销。保留 UTF-8 文本读取边界。
- 移动：目标树、当前选择、确认/取消，根节点可作为目标但不能作为移动源。
- 删除：清楚说明所选对象与递归范围、仅内存阶段与保存关系，默认焦点留在取消；Enter 不默认执行删除。
- 未保存：保存/放弃/取消。所有退出/换文件路径保持现有语义；不能把主题切换当作未保存的书签修改。
- 当前代码的未保存/错误确认使用原生 MessageBox（现有 DiscardChangesDialog 并非实际入口）；实施时为需要统一主题的应用确认建立共用 WPF 对话框，严格映射现有返回值、按钮、默认焦点、关闭即取消和调用顺序。不能因替换弹窗改变 Dirty/恢复保护逻辑。
- 保存失败：区分 Chrome 实际配置正在使用、外部冲突、权限、源缺失、取消、需恢复等情况，复用原有错误内容和恢复/备份路径。
- 空文档、加载中、已取消、空文件夹、搜索无结果、单选、多选、Dirty、可撤销、保存中/失败/成功均有可辨识状态。
- 自有弹窗中途切换主题保持填写内容与验证信息；焦点、Tab 循环、Esc/取消、窗口关闭均有明确安全行为。系统弹窗保持系统行为。
- 复用现有能力门槛：NoDocument、Loading、LoadedClean、LoadedDirty、Saving、SaveFailed、RecoveryRequired、LoadFailed。恢复所需时可浏览但不可编辑或直接再次保存；搜索中禁用按位置重排；右键未选中项切换选择，右键已选项保留多选；Escape 优先清空搜索，否则清除列表选择。
